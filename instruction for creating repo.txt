Інструкція створення  репозиторія для здачі домашки.
1. Створіть на github  новий репозиторій (не забудьте додати .gitignore).
2. Скопіюйте цей рядок, що зікінчується  на .git . Типу такого https://prnt.sc/T7MPZXgyCPtK
3. Зайдіть у себе на комп'ютері в ту папку, де хочете щоб знаходився цей репозиторій.  Відкрийте з того місця термінал (Будь який командний рядок - cmd, термінал в VSC, bash.)
4. Команда, щоб склонувати собі будь-який репозиторій ( в даному випадку, Ваш власний) -
git clone <той рядок що Ви скопіювали (пункт 2)>
5.  Перенесіть сюди свої написані програми.
6. Відкрийте командний рядок із середини тієї самої папки. Ще там знаходиться папка .git - це для контролю правильності дій :blush:
7. команда, що перевіряє стан репозиторія.  Тут треба тільки подивитись , прочитати що пишуть -
git status
8. команда для додавання файлів  до комміту. Крапка  означає, що додати треба всі файли, які в попередній команді висвітились червоним. ЯКщо треба конкретний файл, то замість крапки напишіть назву файла. -
git add .
9. команда для створення комміта. Це означає, що Ви фіксуєте всі останні зміни  на цьому етапі. Але цій комміт  буде існувати тільки у Вас на локальному компі.  -
git commit -m "fix something"
10. Дуже бажано писати змістовні message в лапках.
11. команда щоб пушнути цей комміт на віддалений репозиторій -
git push
